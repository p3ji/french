# Objectif CBC pilot review

This is an original learning resource. B/C tags express intended practice difficulty, not calibrated test equivalence. The reference PDFs remain outside the site. No protected examination content is reproduced.

## Educator review before wider release

Review every passage, answer key, alternative explanation, vocabulary example, and oral guide. Confirm grammatical accuracy, natural Canadian workplace French, one defensible answer, appropriate difficulty, and useful explanation. Record content ID, issue, suggested correction, and reviewer/date. Source files use stable IDs so findings can be applied precisely.

## Learner questionnaire for an external form

Copy these questions into the pilot organizer's preferred questionnaire tool. This repository does not create a form or send messages to participants.

1. Could you choose your goals and begin a session without help? If not, where did you pause?
2. Roughly how long did the session take?
3. Which question or explanation was most helpful? Include the wording if possible.
4. Which wording or answer felt confusing or debatable?
5. When you returned on another day, could you resume your session?
6. What does the site suggest you practise next, and does that recommendation make sense?
7. Was anything hard to read, tap, or use with a keyboard on your device?
8. Would you return for another session? What would make it more useful?

Pilot success: independent onboarding, a completed session, a successful return visit, an understandable next focus, and actionable feedback. Official test-outcome validation is a later study. Keep the initial Sites deployment private to the owner until content and access are reviewed.
